## logoscore test environment (dev-only, fragile)

The installed `.so` at `~/.local/share/Logos/LogosApp/modules/keycard/` has been
manually patched with `patchelf` to include Nix lib paths. NOT in source — must be
re-applied after every `cmake --install`:

```bash
PATHS=$(ldd build/keycard-core/keycard_plugin.so | grep nix | awk '{print $3}' | xargs -I{} dirname {} | sort -u | tr '\n' ':' | sed 's/:$//')
patchelf --set-rpath "\$ORIGIN:$PATHS" ~/.local/share/Logos/LogosApp/modules/keycard/keycard_plugin.so
```

Then start daemon:
```bash
LOGOSCORE=/nix/store/4v00839956lahxv54hf581x58z32nj4r-logos-logoscore-cli/bin/logoscore
$LOGOSCORE -D --modules-dir ~/.local/share/Logos/LogosApp/modules &>/tmp/logoscore-daemon.log &
sleep 3
$LOGOSCORE load-module keycard
$LOGOSCORE call keycard getState
```
